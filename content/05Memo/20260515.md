## ランダム表示ボタンを追加

quartz>quartz>components

ここに、

Random01Page.tsx

というファイルを追加します（ファイル名は分かれば何でも良いです）。

中身はこんな感じです。

色は好みで。

```
import { QuartzComponentConstructor } from "./types"


const Random01Page: QuartzComponentConstructor = () => {

  return () => (
    <div>
      <style>
        {`
          .random-button {
            display: block;
            width: 100%;
            padding: 12px 14px;
            font-size: 16px;
            font-weight: 600;
            border-radius: 10px;
            border: 1px solid var(--lightgray);
            background: #6aa6ce;
            color: #040d13;
            cursor: pointer;
            transition: all 0.15s ease;
          }
  
          .random-button:hover {
            transform: translateY(-1px);
            opacity: 0.9;
          }

          .random-button:active {
            transform: translateY(0px);
          }
        `}

      </style>

      <button id="random-note-button" class="random-button">

        ページをランダム表示

      </button>

      <script

        dangerouslySetInnerHTML={{
          __html: `
            document.addEventListener("DOMContentLoaded", () => {
              const button = document.getElementById("random-note-button")

              if (!button) return
              button.addEventListener("click", async () => {

                try {
                  const res = await fetch("/static/contentIndex.json")
                  const data = await res.json()
                  const pages = Object.keys(data).filter((p) =>
                    p.startsWith("01Page/")
                  )
                  
                  if (pages.length === 0) return

                  const randomPage =
                    pages[Math.floor(Math.random() * pages.length)]
                  window.location.href = "/" + randomPage

                } catch (err) {

                  console.error(err)
                }
              })
            })
          `,
        }}
      />
    </div>
  )
}

export default Random01Page

```

次に、quartz.layout.tsの冒頭に以下のコードを入れます。

```
import Random01Page from "./quartz/components/Random01Page"
```

あとは好きなところ（今回は画面右側）にボタンを置きます。quartz.layout.tsの「export const defaultContentPageLayout: PageLayout = {」内に

```
right: [
    Random01Page(),
  ],

```

と入れます。

## 外部サイトにリンクを貼ったときのプレビュー（OGP）を日本語対応にする

og（OGP？）っていうのが、XとかnoteとかでWebサイトのURLを貼ったときに出てくるプレビューのことらしいです。詳しくはこちらのXServerの記事を読んでください（[外部リンク](https://www.xserver.ne.jp/bizhp/open-graph-protocol/)）。私も勉強します。

初期設定だと日本語対応がされていないので、文字化けします。

Xなどでサイトの宣伝をするときに、ちょっと見栄えが悪いです。そこで、それを改良しました。

これは完全にChatGPT頼りでやったので、ざっくりとだけ説明します。

①フォント「Noto Sans Japanese」をインストールする

こちらからどうぞ（[外部リンク](https://fonts.google.com/noto/specimen/Noto+Sans+JP)）。

ここで入手したフォントを、Boldとか含めて全種類インストールします。

このフォントは、quartz>public>static>fonts

に入れましょう。「fonts」フォルダは自分で作りましょう。

②quartz/plugins/emitters/ogImage.tsxを編集する

const svg = await satori(imageComponent, {

の中に

```
fonts: [
      {
        name: "Noto Sans JP",
        data: notoSans,
        weight: 400,
        style: "normal",
      },
    ],
```

と入れます。

後々のために、async function generateSocialImageの中に
```
  const notoSans = fs.readFileSync(
  path.join(process.cwd(),
  "quartz/static/fonts/NotoSansJP-Regular.ttf")

  )
```


と入れます。

③Node 20にしておく

Node.jsのバージョンによって不具合が出るのかも？とChatGPTに言われたので、その通り試してみました。

GitHubにあるnvm-setup.exeを入れます。

これを開き、設定します。

そしたらコマンドプロンプトで

```
nvm install 20
```

と入れます。

その後、

```
nvm use 20
```

と入れ、Nodeのバージョンを変えます。

次いで、コマンドプロンプトでquartzのフォルダを開き、

```
Remove-Item node_modules -Recurse -Force
```

```
Remove-Item package-lock.json -Force
```

```
npm install
```


④og.tsxをいじる

さて、このファイル内で「export const defaultImage: SocialImageOptions～」とある中に

```
<div
  style={{
    display: "flex",
    fontFamily: "Noto Sans JP",
  }}
>
```

と入れます。

以上で、OGPがうまくできるはず、多分。
